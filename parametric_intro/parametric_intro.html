  1. 1.

    Motivation. Suppose a ball is thrown so that its path is described by

    y=−x272+x,

    where x is the horizontal distance traveled and y is the height of the ball.

    1. (a)

      What information does this Cartesian equation tell us?

      Solution.

      The equation gives the geometric path of the ball. It is a downward-opening parabola.

      Factoring,

      y=x⁢(1−x72),

      shows that the x-intercepts are x=0 and x=72. Thus, if the ball begins and ends at ground level, its horizontal range is 72 feet.

      The vertex occurs at

      x=−b2⁢a=−12⁢(−1/72)=36.

      Then

      y⁢(36)=−36272+36=18.

      Thus the maximum height is 18 feet, attained after 36 horizontal feet.

    2. (b)

      What important information does this equation not tell us?

      Solution.

      It does not tell us how time is related to the motion. In particular, it does not specify the direction of travel, the position at a particular time, or how quickly the ball moves along the curve.

    3. (c)

      Suppose instead that

      x=24⁢2⁢t,y=−16⁢t2+24⁢2⁢t,

      where t is measured in seconds. Why is this description more informative?

      Solution.

      The parameter t gives the ball’s position at each time. It also determines the direction of motion: as t increases, x increases, so the ball moves from left to right.

      The ball returns to ground level when

      −16⁢t2+24⁢2⁢t=0,

      so

      t⁢(−16⁢t+24⁢2)=0.

      Hence

      t=0ort=3⁢22.

      Thus the flight lasts 3⁢22 seconds.

    4. (d)

      Verify that eliminating t produces the original Cartesian equation.

      Solution.

      From

      x=24⁢2⁢t,

      we obtain

      t=x24⁢2.

      Substitute this into y:

      y=−16⁢(x24⁢2)2+24⁢2⁢(x24⁢2).

      Since

      (24⁢2)2=1152,

      we get

      y=−16⁢x21152+x=−x272+x.
  2. 2.

    Definition. Let f and g be continuous on an interval I. The equations

    x=f⁢(t),y=g⁢(t)

    are called parametric equations, and t is called the parameter. As t varies through I, the point

    (x,y)=(f⁢(t),g⁢(t))

    traces a plane curve C.

    Remark. A Cartesian equation describes only the shape of a curve. A parametrization also specifies how the curve is traced, including its initial and terminal points, direction of motion, whether the curve is traced more than once, and the position of the particle for each value of the parameter.

  3. 3.

    Sketching Parametric Curves.

    When sketching a parametric curve it is often helpful to

    1. (a)

      determine the interval for the parameter,

    2. (b)

      eliminate the parameter whenever possible,

    3. (c)

      determine the appropriate Cartesian domain,

    4. (d)

      identify the initial and terminal points,

    5. (e)

      determine the direction in which the curve is traced.

    Solution.

    Example 3. Sketch the curve by eliminating the parameter and finding the correct domain:

    x=1t+1,y=tt+1,t>−1.

    Solution.

    Rewrite y:

    y=tt+1=(t+1)−1t+1=1−1t+1.

    From

    x=1t+1,

    we have

    x2=1t+1.

    Therefore

    y=1−x2.

    The original parametrization imposes an important restriction. Since t>−1,

    t+1>0,

    and

    x=1t+1>0.

    Hence the correct Cartesian domain is

    x>0.

    Thus the curve is the right-hand portion of the parabola

    y=1−x2.

    For direction, as t→−1+,

    x→∞,y=1−x2→−∞.

    As t→∞,

    x→0+,y→1−.

    Therefore the curve is traced from the lower right upward and to the left, approaching (0,1) without reaching it.

    Example 4. Sketch

    x=3⁢cos⁡t,y=4⁢sin⁡t,0≤t≤2⁢π.

    Solution.

    Solve for the trigonometric expressions:

    cos⁡t=x3,sin⁡t=y4.

    Using

    cos2⁡t+sin2⁡t=1,

    we obtain

    x29+y216=1.

    This is an ellipse centered at the origin with horizontal semiaxis 3 and vertical semiaxis 4.

    Example 5. Sketch

    x=2⁢sin⁡2⁢t,y=2⁢cos⁡2⁢t,0≤t≤2⁢π.

    Solution.

    We have

    x2=sin⁡2⁢t,y2=cos⁡2⁢t.

    Therefore

    (x2)2+(y2)2=1,

    so

    x2+y2=4.

    This is a circle centered at the origin with radius 2.

    At t=0,

    (x,y)=(0,2).

    For small positive t, x=2⁢sin⁡2⁢t>0, while y=2⁢cos⁡2⁢t begins to decrease. Thus the point moves from the top of the circle toward the right, which is clockwise.

    As t runs from 0 to 2⁢π, the angle 2⁢t runs from 0 to 4⁢π. Therefore the circle is traced twice, clockwise.

  9. 9.

    Definition of a Smooth Curve. A curve C, represented by

    x=f⁢(t),y=g⁢(t)

    on an interval I, is called smooth if f′ and g′ are continuous on I and are not simultaneously zero, except possibly at the endpoints.

    The curve is called piecewise smooth if the interval can be divided into finitely many subintervals on each of which the curve is smooth.

    Key Idea.

    The vector

    𝐫′⁢(t)=(f′⁢(t),g′⁢(t))

    is the velocity vector of the parametrization. The condition

    𝐫′⁢(t)≠(0,0)

    ensures that the parametrization does not come to a complete stop at an interior point.

  10. 10.

    Example. Determining Whether a Curve is Smooth

    Decide whether each parametric curve is smooth.

    1. (a)

      x=t,y=t2.

      Solution.

      x′⁢(t)=1,y′⁢(t)=2⁢t.

      Since x′⁢(t)≠0 for every t, the derivatives are never simultaneously zero. Therefore the curve is smooth.

    2. (b)

      x=t3,y=t2.

      Solution.

      x′⁢(t)=3⁢t2,y′⁢(t)=2⁢t.

      Both derivatives are zero at t=0. Hence the curve is not smooth. This parametrization produces a cusp because the velocity vector is (0,0) at t=0.
