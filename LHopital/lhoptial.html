Math 252, 8.7 L’Hôpital’s Rule

  1. 1.

    Previously, you learned about some special forms that occur when taking limits. These were called indeterminate forms because the limiting behavior could not be determined simply by plugging the limiting value into the function. Specifically, we considered two types of forms, 0/0 and ∞/∞. Some examples of limits where these forms appear are

    limx→−12⁢x2−2x+1=limx→−12⁢(x+1)⁢(x−1)x+1=limx→−12⁢(x−1)=−4.

    We also had

    limx→∞3⁢x2−12⁢x2+1=32.

    The first example is of the 0/0 type; however, after some algebraic manipulation, we can find its limit. Similarly, in the second example, we can determine the limit by comparing the leading terms. However, not all indeterminate forms can be evaluated through algebraic manipulation. This is often true when both algebraic and transcendental functions are involved. For example,

    limx→0e2⁢x−1x.

    Through a process of plugging in numbers, we may eventually see that the limit is close to 2. However, this is not a good strategy every time we need to evaluate a limit.

  2. 2.

    L’Hôpital’s Rule. Assume that f and g are differentiable functions on an interval containing x=a, except possibly at a. Assume further that g′⁢(x)≠0 near a. If

    limx→af⁢(x)=0andlimx→ag⁢(x)=0,

    and if

    limx→af′⁢(x)g′⁢(x)

    exists or is infinite, then

    limx→af⁢(x)g⁢(x)=limx→af′⁢(x)g′⁢(x).

    To see why this rule is plausible in the case where f⁢(a)=g⁢(a)=0, note that

    limx→af⁢(x)g⁢(x) =limx→af⁢(x)−f⁢(a)g⁢(x)−g⁢(a)
    =limx→af⁢(x)−f⁢(a)x−ag⁢(x)−g⁢(a)x−a
    =limx→af⁢(x)−f⁢(a)x−alimx→ag⁢(x)−g⁢(a)x−a
    =f′⁢(a)g′⁢(a).
    L’Hôpital’s Rule.

    If the limit is in the form 0/0 or ∞/∞, then

    limx→af⁢(x)g⁢(x)=limx→af′⁢(x)g′⁢(x),

    provided the limit on the right exists or is infinite.

    Similarly, for the ∞/∞ form, we may rewrite the quotient as

    f⁢(x)g⁢(x)=1g⁢(x)1f⁢(x).

    When we take the limit, the reciprocal form becomes a 0/0 form, so we can use L’Hôpital’s Rule. Hence,

    limx→af⁢(x)g⁢(x) =limx→a1g⁢(x)1f⁢(x)
    =limx→a−g′⁢(x)g⁢(x)2−f′⁢(x)f⁢(x)2
    =limx→ag′⁢(x)f′⁢(x)⋅limx→a(f⁢(x))2(g⁢(x))2
    =limx→ag′⁢(x)f′⁢(x)⋅(limx→af⁢(x)g⁢(x))2.

    Rearranging terms gives

    limx→af⁢(x)g⁢(x)=limx→af′⁢(x)g′⁢(x)

    for the ∞/∞ form also.

    Remark.

    In order to use L’Hôpital’s Rule, the problem must first be in the form 0/0 or ∞/∞. Sometimes this is clear. Other indeterminate forms require algebra before the method can be used, including

    1. (a)

      0⋅∞,

    2. (b)

      1∞,

    3. (c)

      00.

  3. 3.

    Example 1: Evaluate limx→0e2⁢x−1x.

    Solution. Since both the numerator and the denominator are continuous, substituting x=0 gives 0/0. Hence, this is an indeterminate form. Since it is a 0/0 form, we can use L’Hôpital’s Rule:

    limx→0e2⁢x−1x =limx→0dd⁢x⁢[e2⁢x−1]dd⁢x⁢[x]
    =limx→02⁢e2⁢x1
    =2.
  4. 4.

    Example 2: Evaluate limx→∞ln⁡xx.

    Solution. Since both functions are continuous, we evaluate the limit form and obtain ∞/∞, which is indeterminate. So we use L’Hôpital’s Rule:

    limx→∞ln⁡xx =limx→∞1/x1
    =0.

    Remark. If we compare the graphs of f⁢(x)=ln⁡x and g⁢(x)=x, we see that g grows much faster than f. Therefore, at infinity, the denominator dominates, giving a limit of 0.

  5. 5.

    Example 3: Evaluate limx→−∞x2e−x.

    Solution. We get ∞/∞ in this problem. Hence,

    limx→−∞x2e−x =limx→−∞2⁢x−e−x which is again ⁢∞/∞
    =limx→−∞2e−x
    =0.

    Question: How could you have figured this limit out without using this rule? Hint: think about the graphs.

  6. 6.

    Example 4: Evaluate limx→∞e−x⁢x.

    Solution. This is a 0⋅∞ form, but it is not L’Hôpital ready. Note that

    limx→∞e−x⁢x =limx→∞xex
    =limx→∞12⁢x−1/2ex
    =0.
  7. 7.

    Example 5: Evaluate limx→0+x3⁢cot⁡x.

    Solution. This is a 0⋅∞ form, but it is not L’Hôpital ready. So, we perform a slight trick:

    limx→0+x3⁢cot⁡x =limx→0+cot⁡x1x3 which is now an ⁢∞/∞⁢ form
    =limx→0+−csc2⁡x−3/x4
    =limx→0+x43⁢sin2⁡x
    =limx→0+4⁢x36⁢sin⁡x⁢cos⁡x
    =limx→0+12⁢x26⁢(cos2⁡x−sin2⁡x)
    =0.
  8. 8.

    Example 6: Evaluate limx→∞(1+1x)x.

    Solution. This is a 1∞ form; however, it is not L’Hôpital ready. Let

    y =limx→∞(1+1x)x.

    Then

    ln⁡y =ln⁡[limx→∞(1+1x)x]
    =limx→∞ln⁡[(1+1x)x]
    =limx→∞x⁢ln⁡(1+1x)
    =limx→∞ln⁡(1+1x)1/x
    =limx→∞−1/x21+(1/x)−1/x2
    =limx→∞11+(1/x)
    =1.

    Therefore,

    y=e1=e.
  9. 9.

    Example 7: Evaluate limx→0+(sin⁡x)x.

    Solution. This is a 00 form, but it is not in the right form for L’Hôpital’s Rule. Let

    y=limx→0+(sin⁡x)x.

    Then

    ln⁡y =limx→0+ln⁡[(sin⁡x)x]
    =limx→0+x⁢ln⁡(sin⁡x)
    =limx→0+ln⁡(sin⁡x)1/x
    =limx→0+cot⁡x−1/x2
    =limx→0+−x2tan⁡x
    =limx→0+−2⁢xsec2⁡x
    =0.

    Therefore,

    y=1.
  10. 10.

    Le Marquis de l’Hôpital (1661–1704). L’Hôpital’s Rule should actually be called “Bernoulli’s Rule” because it appears in correspondence from Johann Bernoulli to L’Hôpital. But L’Hôpital and Bernoulli had made an agreement under which L’Hôpital paid Bernoulli a monthly fee for solutions to certain problems, with the understanding that Bernoulli would tell no one of the arrangement. L’Hôpital’s Rule first appeared publicly in L’Hôpital’s 1696 calculus book. It was only recently discovered that the rule, its proof, and relevant examples all appeared in a 1694 letter from Bernoulli to L’Hôpital.
