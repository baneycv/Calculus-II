Math 252, Review and 7.1: Riemann Integral and Area Between Curves

  1. 1.

    Recall. Assume that f⁢(x) is continuous on the interval [a,b]. We partition the interval into n subintervals, so that the distance of each subinterval was, for 1≤k≤n

    Δ⁢x=b−an

    and

    a=x0<x1<x2<⋯<xk<⋯<xn=b

    where

    xk=a+k⁢Δ⁢x

    If we were finding the area for example, Δ⁢x gave us the width of the rectangle that we were placing in the function to estimate. The height of the rectangle can be found using the left-endpoint rule, right endpoint rule, midpoint rule, or any point inside the subinterval. So, assuming we are looking at a subinterval [xk−1,xk], we can pick any point inside that interval, so that xk−1≤tk≤xk to evaluate the function to find the height of the rectangle, f⁢(tk).

    Finding the area of one rectangle, we have that

    Ak=f⁢(tk)⁢(xk−xk−1)=f⁢(tk)⁢Δ⁢x.

    Summing up all of the n rectangles, we would find that

    An=∑k=1nf⁢(tk)⁢Δ⁢x.

    We observed in Calculus I (and the Worksheet 1), so long as f is non-negative and continuous for all x in [a,b], that as n→∞, Δ⁢x→0, and we would find that,

    A=limn→∞∑k=1nf⁢(tk)⁢Δ⁢x=I

    We know that the Riemann Sum converges, and it converges to the integral (antiderivative)

    I=∫abf⁢(x)⁢𝑑x

    So this quantity’s physical meaning is the area (it could also be the distance if f were velocity and Δ⁢x time).
    Laslty, if we know that there is a function F defined on [a,b] such that F′⁢(x)=f⁢(x) for all x in [a,b], then, so long as f is continuous, we have that,

    ∫abf⁢(x)⁢𝑑x=F⁢(b)−F⁢(a).
  2. 2.

    Example 1: Let f⁢(x)=x1/3. Determine the area bounded between the graph of f and the x-axis for 1≤x≤8.
    Solution: Since f⁢(x)≥0 on the interval, we can evaluate the definite integral. In this case, we can think of the height of the rectangle to be f⁢(x)=x1/3, and d⁢x as the width. Thus, A∗=x1/3⁢d⁢x. We then add these value over the interval [1,8].

    ∫18x1/3⁢𝑑x = [x4/34/3]18
    = [34⁢x4/3]18
    = 34⁢(84/3)−34⁢(14/3)
    = 34⁢(16)−34⁢(1)
    = 12−34
    = 454.
  3. 3.

    What Happens if f is negative? Consider again a function f⁢(x)≤0 for all x in the interval a≤x≤b, and let R be the region bounded between the graph of f and the x-axis.

    If we were to consider the Riemann Sum in this case for a=x0<x1<x2<⋯<xk<⋯<xn=b, we would find that we would be adding values that are all negative or equal to zero. That is to say that

    f⁢(a)+f⁢(x1)+f⁢(x2)+⋯+f⁢(b)≤0.

    Thus the integral would yield a negative value, which could not be the area under the curve as area must be a positive quantity. Thus, we have the following, that for f⁢(x)≤0 on [a,b], we have that

    ∫abf⁢(x)⁢𝑑x=−(area of R).

    Example 2: Let

    f⁢(x)=x2−4.

    Determine the area bounded between the graph of f and the x-axis on

    0≤x≤3.

    Solution: Note that the graph of f is below the x-axis for 0≤x≤2, and then positive again for 2≤x≤3. Thus, we have to break the integral up into two parts in order to evaluate the area under the curve.

    Area = −∫02(x2−4)⁢𝑑x+∫23(x2−4)⁢𝑑x
    = −[x33−4⁢x]02+[x33−4⁢x]23
    = −[(83−8)−0]+[(9−12)−(83−8)]
    = −(−163)+[−3−(−163)]
    = 163+73
    = 233.

    Area Between Curves Now we are interested in finding the area between two curves. Assume that f⁢(x) and g⁢(x) are continuous functions on the interval [a,b]

    Following the same procedure as above, we partition the interval into n subintervals, so that Δ⁢x=b−an, and for 1≤k≤n, xk=a+k⁢Δ⁢x, so that a=x0<x1<x2<⋯<xk<⋯<xn=b. See the figure below,

    We pick tk in each interval [xk−1,xk] to evaluate the function to find the height of the rectangle. We see to get the complete height, we see that we subtract the values of the functions, f⁢(tk)−g⁢(tk), and putting it all together, we get

    Aa⁢p⁢p⁢r⁢o⁢x=∑k=1n[f⁢(tk)−g⁢(tk)]⁢Δ⁢x

    We take n→∞ so Δ⁢x→0, and we find that

    A=limn→∞∑k=1n[f⁢(tk)−g⁢(tk)]⁢Δ⁢x=∫ab[f⁢(x)−g⁢(x)]⁢𝑑x (1)
    1. (a)

      In order to use this formula we need to know which function is on the top and which one is on the bottom as that will make a difference as to the order in which we subtract

    2. (b)

      We also have to be aware of whether or not the graphs intersect on the interval, and if they switch positions as we would then need to have two integrals.

    Example 3: Find the area of the region bounded by the graph y=x2+2 and y=−x, x=0 and x=1.
    Solution: We start by drawing picture, and from that we determine which graph is on top.

    A = ∫01[(x2−1)−(−x)]⁢𝑑x
    = ∫01(x2+x−1)⁢𝑑x
    = x33+x22−x|01
    = 176

    Example 5: Find the area of the region between the graph of f⁢(x)=3⁢x3−x2−10⁢x and g⁢(x)=−x2+2⁢x.
