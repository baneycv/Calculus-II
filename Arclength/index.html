Math 252, 7.4 Arc Length

  1. 1.

    Situation. Let y=f⁢(x) be a continuous function on the interval [a,b], see the figure below.

    "

    We wish to find the length of the curve across the interval. Again, we find ourselves in a situation where we do not know a formula for this because the curve is not a circle, with a simple formula. The only thing we know how to find the length of is a line. Given a segment between the points (x1,y1), and (x2,y2), the length of the segment that connects the two points is given by

    s=(x1−x2)2+(y1−y2)2.

    We use this idea in order to help us find the length of the curve, by cutting the curve up into n TINY line segments between (xk−1,f⁢(xk−1)) and (xk,f⁢(xk)) for 1≤k≤n.

  2. 2.

    Derivation. We partition the interval [a,b] into n subintervals so that Δ⁢x=b−an. The partition will consist of a=x0<x1<x2<⋯<xk<⋯<xn=b. For each consecutive interval [xk−1,xk], we create a line segment whose coordinates are given by (xk−1,f⁢(xk−1)) and (xk,f⁢(xk)), and find the distance between the points using the distance formula,

    Δ⁢s=(xk−xk−1)2+(f⁢(xk)−f⁢(xk−1))2

    Recalling the Mean-Value Theorem, we have that there is a value tk in xk−1≤tk≤xk such that

    f⁢(tk)−f⁢(tk−1)=f′⁢(tk)⁢(xk−xk−1).

    Inserting this expression into the distance formula, we get,

    Δ⁢s = (xk−xk−1)2+(f′(tk)(xk−xk−1)2
    = (xk−xk−1)2[1+(f(tk))2
    = 1+[f⁢(tk)]2⁢(xk−xk−1)
    = 1+[f⁢(tk)]2⁢Δ⁢x

    We add all n of these up to get the Riemann Sum,

    sn=∑k=1n1+[f⁢(tk)]2⁢Δ⁢x

    As n→∞, Δ⁢x→0, we get,

    s=∫ab1+[f⁢(x)]2⁢𝑑x
  3. 3.

    Approach to using Formula In general, square roots are undesirable in integrals. They are difficult to manipulate. Hence, we use the following procedure.

    1. (a)

      Determine the derivative, f′.

    2. (b)

      Find 1+(f′)2, simplify and factor so that it comes out to be a perfect square. ALL THE PROBLEMS YOU WILL ENCOUNTER RIGHT NOW WILL BE PERFECT SQUARES.

    3. (c)

      After you simplify and factor to form a perfect square, take the square root and integrate.

  4. 4.

    Perfect Squares Recall the following a2+2⁢a⁢b+b2=(a+b)2, and a2−2⁢a⁢b+b2=(a−b)2. Some example of the ones that you are likely to encounter are,

    1. (a)

      The expression tan2⁡x+1=sec2, which is a perfect square.

    2. (b)

      The expression x24−12+14⁢x2=(x2−12⁢x)2.

  5. 5.

    Example 1: Find the arc length of

    y=x36+12⁢x

    on [12,2].

    Solution:

    1. (a)

      First determine f′. f′⁢(x)=x22−12⁢x2.

    2. (b)

      Find 1+(f′)2. First, we see that,

      (f′⁢(x))2=x44−12+14⁢x2
    3. (c)

      Next, we have that

      1+(f′⁢(x))2 = x44+12+14⁢x2
      = (x22+12⁢x2)2
    4. (d)

      Evaluate 1+(f′⁢(x))2 which gives us, 1+(f′)2=x22+12⁢x2

    5. (e)

      Evaluate the integral,

      s = ∫ab1+[f′⁢(x)]2⁢𝑑x
      = ∫1/22(x22+12⁢x2)⁢𝑑x
      = x36−12⁢x|1/22
      = 3316
  6. 6.

    Example 2: Let y=ln⁡(cos⁡x) on [0,π/4]. Determine the length of the curve.
    Solution:

    1. (a)

      First determine f′. f′⁢(x)=−sin⁡xcos⁡x=−tan⁡x.

    2. (b)

      Find 1+(f′)2. First, we see that,

      (f′⁢(x))2=tan2⁡x
    3. (c)

      Next, we have that

      1+(f′⁢(x))2 = 1+tan2⁡x
      = sec2⁡x
    4. (d)

      Evaluate 1+(f′⁢(x))2 which gives us, 1+(f′)2=sec⁡x

    5. (e)

      Evaluate the integral,

      s = ∫ab1+[f′⁢(x)]2⁢𝑑x
      = ∫0π/4sec⁡x⁢d⁢x
      = ln⁡|sec⁡x+tan⁡x||0π/4
      = ln⁡|2+1|−ln⁡|1|
      = ln⁡(2+1).
