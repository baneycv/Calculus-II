Math 252, 8.8 Improper Integrals

  1. 1.

    The First Fundamental Theorem of Calculus There are essentially two parts of the Fundamental Theorem of Calculus. If a function f is continuous on the closed interval [a,b], and F is the antiderivative of f on the interval [a,b], then

    ∫abf⁢(x)⁢𝑑x=F⁢(b)−F⁢(a).

    This theorem raises the question: what happens if the limits of integration are infinite, that is, the interval is of infinite length, or if f has an infinite discontinuity, that is, a vertical asymptote, at one of the bounds of integration? If either situation occurs, the integral is called an improper integral.

    1. (a)

      Consider the integral ∫1∞1x2⁢𝑑x. This integral is improper because the interval is not bounded. In order to evaluate this integral, we create a finite boundary at the right and evaluate the integral using the Fundamental Theorem of Calculus. After that, we permit the bound to go to infinity.

      Hence, we have that

      ∫1∞1x2⁢𝑑x =limb→∞∫1b1x2⁢𝑑x
      =limb→∞−1x|1b
      =limb→∞(1−1b)
      =1.
    2. (b)

      Definition of Improper Integral with Infinite Integration Limits

      Definition.
      • •

        If f is continuous on the interval [a,∞), then

        ∫a∞f⁢(x)⁢𝑑x=limb→∞∫abf⁢(x)⁢𝑑x.
      • •

        If f is continuous on the interval (−∞,b], then

        ∫−∞bf⁢(x)⁢𝑑x=lima→−∞∫abf⁢(x)⁢𝑑x.
      • •

        If f is continuous on the interval (−∞,∞), then, for any real number c, we have that

        ∫−∞∞f⁢(x)⁢𝑑x=∫−∞cf⁢(x)⁢𝑑x+∫c∞f⁢(x)⁢𝑑x.
      • •

        If the improper integral has a finite limit, the integral is said to converge. Otherwise, the integral is said to diverge.

  2. 2.

    Example 1: Evaluate ∫1∞d⁢xx.

    Solution:

    ∫1∞1x⁢𝑑x =limb→∞∫1b1x⁢𝑑x
    =limb→∞ln⁡x|1b
    =limb→∞(ln⁡b−ln⁡1)
    =limb→∞ln⁡b
    =∞.

    Hence, this integral diverges because the limit is infinite.

  3. 3.

    Example 2: Evaluate ∫1∞e−x⁢𝑑x.

    Solution:

    ∫0∞e−x⁢𝑑x =limb→∞∫0be−x⁢𝑑x
    =limb→∞−e−x|0b
    =limb→∞(1−e−b)
    =1.

    Hence the integral converges because the limit is finite.

  4. 4.

    Example 3: Evaluate ∫1∞1x2+1⁢𝑑x.

    Solution:

    ∫0∞1x2+1⁢𝑑x =limb→∞∫0b1x2+1⁢𝑑x
    =limb→∞arctan⁡x|0b
    =limb→∞(arctan⁡b−arctan⁡0)
    =π2.

    Hence the integral converges because the limit is finite.

  5. 5.

    Example 4: Evaluate ∫1∞(1−x)⁢e−x⁢𝑑x.

    Solution:

    We use integration by parts. Let u=1−x, so d⁢u=−d⁢x, and d⁢v=e−x⁢d⁢x, so v=−e−x.

    ∫1∞(1−x)⁢e−x⁢𝑑x =limb→∞∫1b(1−x)⁢e−x⁢𝑑x
    =limb→∞[−e−x⁢(1−x)|1b−∫1be−x⁢𝑑x]
    =limb→∞x⁢e−x|1b
    =limb→∞(b⁢e−b−e−1)
    =−1e.

    Hence the integral converges because the limit is finite.

  6. 6.

    Example 5: Evaluate ∫−∞∞ex1+e2⁢x⁢𝑑x.

    Solution:

    We use integration by substitution, where u=ex, so d⁢u=ex⁢d⁢x.

    ∫−∞∞exe2⁢x+1⁢𝑑x =∫−∞0exe2⁢x+1⁢𝑑x+∫0∞exe2⁢x+1⁢𝑑x
    =lima→−∞∫a0exe2⁢x+1⁢𝑑x+limb→∞∫0bexe2⁢x+1⁢𝑑x
    =lima→−∞arctan⁡ex|a0+limb→∞arctan⁡ex|0b
    =lima→−∞(arctan⁡e0−arctan⁡ea)+limb→∞(arctan⁡eb−arctan⁡e0)
    =(arctan⁡1−0)+(π2−arctan⁡1)
    =(π4−0)+(π2−π4)
    =π2.
  7. 7.

    Definition of Improper Integrals with Infinite Discontinuities

    Definition.
    • •

      If f is continuous on the interval [a,b), then

      ∫abf⁢(x)⁢𝑑x=limc→b−∫acf⁢(x)⁢𝑑x.
    • •

      If f is continuous on the interval (a,b], then

      ∫abf⁢(x)⁢𝑑x=limc→a+∫cbf⁢(x)⁢𝑑x.
    • •

      If f is continuous on the interval [a,b], except for some number c, we have that

      ∫abf⁢(x)⁢𝑑x=∫acf⁢(x)⁢𝑑x+∫cbf⁢(x)⁢𝑑x.
    • •

      If the improper integral has a finite limit, the integral is said to converge. Otherwise, the integral is said to diverge.

  8. 8.

    Example 6: Evaluate ∫011x3⁢𝑑x.

    Solution:

    ∫01x−1/3⁢𝑑x =limc→0+∫c1x−1/3⁢𝑑x
    =limc→0+32⁢x2/3|c1
    =limc→0+(32−32⁢c2/3)
    =32.

    Hence the integral converges.

  9. 9.

    Example 7: Evaluate ∫−121x3⁢𝑑x.

    Solution:

    ∫−121x3⁢𝑑x=limc→0−∫−1cx−3⁢𝑑x+limd→0+∫d2x−3⁢𝑑x.

    If we evaluate the second integral, we find that it diverges. Therefore, the entire integral diverges.
