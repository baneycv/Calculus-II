Math 252, 7.3 Shell Method

  1. 1.

    Situation. We now turn to problems involving surfaces formed by revolving a region D around the y-axis. Note: The presentation of the material is different that it is in your textbook. I find this approach to the derivation of the formula much more intuitive than your textbook. The concept is the same though. The set up of the problem is such that we have two graphs g⁢(x) and f⁢(x) on [a,b]. We assume both functions are continuous on the interval. Secondly g⁢(x)≤f⁢(x) for all x on [a,b]. Let D by the region bounded between the two graphs, and suppose that we want to find the volume of the solid obtained by revolving D around the y-axis.

    Our desire is to use some partition of the x axis in order to accomplish this. Hence, we partition the interval up into n-subintervals, each of width Δ⁢x=b−an. The points created by such a partition are a=x0<x1<x2<⋯<xk<⋯<xn=b, for 1≤k≤n, where xk=a+k⁢Δ⁢x. In each interval we can define a rectangle by defining the height of the rectangle by the function value at some point, tk. In this case, I am going to take tk to be the midpoint, thus

    tk=xk+xk−12.

    So we have a rectangle of width Δ⁢x and height f⁢(tk)−g⁢(tk) . We spin this rectangle around the y-axis, creating a cylindrical shell (cylinder with a hole in it).

    We do this for each rectangle, creating something like a bunch of nesting cups each with a certain volume. We will add up all those smaller volumes to get the bigger one.

    1. (a)

      Volume of one cylindrical shell. The height is f⁢(tk)−g⁢(tk). Since there is an inner and outter portion to to the cylinder we need the inner and outter radii. The inner one is going to be xk−1, and the outter radius is xk. Hence the volume is

      Δ⁢V = π⁢xk2⁢f⁢(tk)−π⁢xk−12⁢g⁢(tk)
      = π⁢(f⁢(tk)−g⁢(tk))⁢(xk2−xk−12)
      = π⁢(f⁢(tk)−g⁢(tk))⁢(xk+xk−1)⁢(xk−xk−1)
      = 2⁢tk⁢π⁢(f⁢(tk)−g⁢(tk))⁢Δ⁢x

      In the last step, I used the fact that each point is spaced Δ⁢x from its neighbor, and so xk−xk−1=Δ⁢x. Also, since tk=xk+xk−12, I can replace the expression with 2⁢tk.

    2. (b)

      Adding up all the volumes, we get

      Vn=∑k=1n2⁢tk⁢π⁢(f⁢(tk)−g⁢(tk))⁢Δ⁢x

      Taking n→∞, this Riemann Sum converges, and it converges to

      V=∫ab2⁢π⁢x⁢(f⁢(x)−g⁢(x))⁢𝑑x

    3. (c)

      REMEMBER We do the Riemann Sum so that we know what each of the components of the integral formula represent. You should be able to identify that difference in f and g is the height of the object, the x and d⁢x collectively represent the volume. Since d⁢x represents a change in the x-values, any shift left or right of the axis or rotation will only effect the x, NOT the d⁢x.

  2. 2.

    Example 1: Let f⁢(x)=x−x3, and let D be the region bounded between the graph of f and the positive x-axis. Determine the volume of the solid formed revolving D around the y-axis.
    Solution: We draw a 2-D picture of f. Since we are given only one function, we can assume g⁢(x)=0.

    We can see from the graph, the interval is [0,1]. The height of the revolved object is going to be f⁢(x). The radius is going to be x⁢d⁢x, and so the integral for the volume becomes,

    V = ∫012⁢π⁢x⁢f⁢(x)⁢𝑑x
    = ∫012⁢π⁢x⁢(x−x3)⁢𝑑x
    = ∫012⁢π⁢(x2−x4)⁢𝑑x
    = 2⁢π⁢[x33−x55]01
    = 4⁢π15
  3. 3.

    Example 2: Let f⁢(x)=x2+1, and let D be the region bounded between x=0, y=0 and y=1. Determine of the volume of the solid formed by revolving D around the y-axis.
    Solution: We start by drawing a picture of the situation.

    We identify the important parts of the formula. The radius will remain x⁢d⁢x, the height, will be f⁢(x), and so we get

    V = ∫012⁢π⁢x⁢f⁢(x)⁢𝑑x
    = ∫012⁢π⁢x⁢(x2+1)⁢𝑑x
    = 2⁢π⁢[x44+x22]01
    = 3⁢π2
  4. 4.

    Example 3: Find the volume of the solid formed by revolving the region bounded by the graphs of y=x3+x+1 , y=1, and x=1, around the line x=2.
    Solution: Since this graph is being revolved around an axis parallel to the y-axis, we use the Shell Method. We first draw a picture of the situation.

    Since the axis is shifted this means the radius of our formula will be altered. Writing down the formula for the Shell Method (with the terms moved about),

    V=∫abx⁢d⁢x⏟together these terms make the radius⁢2⁢π⁢(f⁢(x)−g⁢(x))⏟height.

    Since the radius is to the right of the graph, its value will be (2−x). Furthermore, d⁢x presents the change in x and so since all the x values are shifting to the right by 2, d⁢x should remained unchanged. If we were to dialate the function (make everything twice as big or small), then d⁢x would need to reflect this. Remember d⁢x represents how we are measuring along the x axis.
    Also, since the function is bounded between y=1 and the value y=3. The height of the function is going to be f(x)−1.

    Setting up our integral we get,

    V = 2⁢π⁢∫01(2−x)⁢(x3+x+1−1)⁢𝑑x
    = 2⁢π⁢∫01(−x4+2⁢x3−x2+2⁢x)⁢𝑑x
    = 2⁢π⁢[−x55+x44−x33+x2]01
    = 29⁢π15
