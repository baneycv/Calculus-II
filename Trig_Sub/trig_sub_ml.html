Math 252, 8.4 Trigonometric Substitution

  1. 1.

    Purpose. We now explore Integrals that contain square roots that are in the form of a2−x2, x2+a2, x2−a2. The goal is to eliminate the square root from the problem. To this end, we use these substitutions, and corresponding triangles, Trigonometric Substitution (a>0)

    Trigonometric Substitution.

    For integrals involving a2−u2, let

    u=a⁢sin⁡z⟹ua=sin⁡z

    Then a2−u2=a⁢cos⁡z where −π/2<z<π/2. Furthermore

    Trigonometric Substitution.

    For integrals involving u2+a2, let

    u=a⁢tan⁡z⟹ua=tan⁡z

    Then u2+a2=a⁢sec⁡z where −π/2<z<π/2. Furthermore

    Trigonometric Substitution.

    For integrals involving u2−a2, let

    u=a⁢sec⁡z⟹ua=sec⁡z

    Then u2−a2=a⁢tan⁡z where −π/2<z<π/2. Furthermore

    Before using this for an integration technique, we will (1) Become familiar with the algebra associated with simplifying these types of integrals, (2) Examine how they induce a right triangle configuration, and then (3) put these ideas together to integrate.

  2. 2.

    Example 1: Suppose x=5⁢sin⁡z. Simplify 25−x2.
    Solution:

    25−x2 = 25−(5⁢sin⁡z)2
    = 25−25⁢sin2⁡z
    = 25⁢(1−sin2⁡z)
    = 25⁢cos2⁡z
    = 5⁢cos⁡z

    Example 2: Suppose x=3⁢tan⁡z. Simplify x2+9.
    Solution:

    x2+9 = (3⁢tan⁡z)2+9
    = 9⁢tan2⁡z+9
    = 9⁢(tan2⁡z+1)
    = 9⁢sec2⁡z
    = 3⁢sec⁡z

    Example 3: Suppose x=a⁢sec⁡z. Simplify x2−a2.
    Solution: Similarly, for x2−a2, we let x=a⁢sec⁡z for π/2<z<π/2, we have that,

    x2−a2 = (a⁢sec⁡z)2−a2
    = a2⁢sec2⁡z−a2
    = a2⁢(sec2⁡z−1)
    = a2⁢tan2⁡z
    = a⁢tan⁡z

    Trigonometric Ratios Review

    When converting answers back into terms of x, we frequently use right triangles and the basic trigonometric ratios. Using the following triangle

    Trigonometric Ratios.
    sin⁡z=yrcos⁡z=xr
    tan⁡z=yxsec⁡z=rx
    csc⁡z=rycot⁡z=xy

    Example 4: Suppose

    sin⁡z=x3.

    Find cos⁡z.
    Solution: Draw a right triangle with opposite side x and hypotenuse 3. By the Pythagorean Theorem,

    r=9−x2.

    Therefore,

    cos⁡z=9−x23.

    Example 6: Suppose

    tan⁡z=x4.

    Find sec⁡z.

    Solution:

    Since

    tan⁡z=yx,

    By the Pythagorean Theorem,

    r2=x2+42=x2+16.

    Therefore,

    r=x2+16.

    Since

    sec⁡z=rx,

    we obtain

    sec⁡z=r4=x2+164.

    Example 5: Evaluate ∫d⁢xx2⁢9−x2.
    Solution: Let x=3⁢sin⁡z, d⁢x=3⁢cos⁡z⁢d⁢z, x/3=sin⁡z and arcsin⁡(x/3)=z.

    d⁢xx2⁢9−x2 = 3⁢cos⁡z⁢d⁢z(3⁢sin⁡z)2⁢9−(3⁢sin⁡z)2
    = 3⁢cos⁡z⁢d⁢z9⁢sin2⁡z⁢9−9⁢sin2⁡z
    = 3⁢cos⁡z⁢d⁢z9⁢sin2⁡z⁢9⁢(1−sin2⁡z)
    = 3⁢cos⁡z⁢d⁢z9⁢sin2⁡z⁢9⁢cos2⁡z
    = 3⁢cos⁡z⁢d⁢z9⁢sin2⁡z⋅3⁢cos⁡z
    = d⁢z9⁢sin2⁡z
    = 19⁢csc2⁡z⁢d⁢z

    Thus,

    ∫19⁢csc2⁡z⁢d⁢z=−19⁢cot⁡z+C

    Using the triangle, we can get this back into terms of x, obtaining

    ∫d⁢xx2⁢9−x2=−9−x29⁢x+C

    Example 6: Evaluate ∫d⁢x4⁢x2+1.
    Solution: Notice that 4⁢x2+1=(2⁢x)2+1. So we let 2⁢x=tan⁡z, 2⁢d⁢x=sec2⁡z⁢d⁢z which means d⁢x=12⁢sec2⁡d⁢z, and arctan⁡2⁢x=z.

    d⁢x(2⁢x)2+1 = 12⁢sec2⁡z⁢d⁢z(tan⁡z)2+1
    = 12⁢sec2⁡z⁢d⁢zsec2⁡z
    = 12⁢sec2⁡z⁢d⁢zsec⁡z
    = 12⁢sec⁡z⁢d⁢z
    12⁢∫sec⁡z⁢d⁢z=12⁢ln⁡|sec⁡z+tan⁡z|+C

    Putting things back in terms of x using the triangle,

    ∫d⁢x4⁢x2+1=12⁢ln⁡|4⁢x2+1+2⁢x|+C

    Example 7: Evaluate ∫x2−3x⁢𝑑x.
    Solution: Let x=3⁢sec⁡z, d⁢x=3⁢sec⁡z⁢tan⁡z⁢d⁢z, x/3=sec⁡z and sec−1⁡(x/3)=z.

    x2−3x⁢d⁢x = 3⁢sec⁡z⁢tan⁡z⁢(3⁢sec⁡z)2−3⁢d⁢z3⁢sec⁡z

    Integrating,

    ∫3⁢tan2⁡z⁢d⁢z = ∫3⁢(sec2⁡z−1)⁢𝑑z

    Example 8: Evaluate

    ∫01d⁢x1+x2.

    Solution:

    Since the integrand contains 1+x2, we use the substitution

    x=tan⁡θ.

    Then

    d⁢x=sec2⁡θ⁢d⁢θ

    and

    1+x2=1+tan2⁡θ=sec2⁡θ.

    Rather than drawing a triangle, we convert the limits of integration.

    When x=0,

    tan⁡θ=0⟹θ=0.

    When x=1,

    tan⁡θ=1⟹θ=π4.

    Therefore,

    ∫01d⁢x1+x2=∫0π/4sec2⁡θsec2⁡θ⁢𝑑θ=∫0π/41⁢𝑑θ.
    =θ|0π/4=π4.
