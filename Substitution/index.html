Math 252, 5.5: Integration by Substitution

  1. 1.

    Recall the Chain Rule for Differentiation

    dd⁢x(f(g(x))=f′(g(x))⋅g′(x)

    This provides a template for handling integrals of composite functions of the form

    ∫f′⁢(g⁢(x))⁢g′⁢(x)⁢𝑑x
  2. 2.

    When do we use it. You should think of integration by substitution in almost the same way as the chain rule. It is used whenever a composition of functions is present. Some key expressions where this happens are: (a⁢x+b)r, f⁢(x), ek⁢x, sin⁡k⁢x, cos⁡k⁢x, etc. We apply it in the following way,

    ∫f′⁢(g⁢(x)⏟u)⁢g′⁢(x)⁢d⁢x⏟d⁢u=∫f′⁢(u)⁢𝑑u
  3. 3.

    Strategy. We use a method called u-substitution.

    • •

      Identify the inner and outer function.

    • •

      Let u=g⁢(x)

    • •

      Find d⁢u and solve for d⁢x.

    • •

      Plug into the integral (you should get an integral that you can evaluate using elementary techniques that we learned previously).

  4. 4.

    Issues to consider. It is not always going to be the case that the d⁢u is present in the problem. The main issue we encounter when it comes to any substitutionary method is how to represent the differential in the integral. Thus, most of the work will go into finding the correct expression for d⁢x.

  5. 5.

    Example 1: Evaluate ∫sin⁡(3⁢x+2)⁢𝑑x.

    Solution:. We see that we have a function inside of a function.

    ∫sin⁡(3⁢x+2⏟u)⁢𝑑x

    Let u be the inner function. Once we find u, differentiate to find d⁢u, and then solve for d⁢x.

    u = 3⁢x+2
    d⁢u = 3⁢d⁢x
    13⁢d⁢u = d⁢x

    Using the u and the d⁢x, we substitute into the problem,

    ∫sin⁡(3⁢x+2)⁢𝑑x = ∫sin⁡u⁢13⁢d⁢u
    = 13⁢∫sin⁡u⁢d⁢u
    = −13⁢cos⁡u+C

    Replacing u with the original expression in x,

    ∫sin⁡(3⁢x+2)⁢𝑑x=−13⁢cos⁡(3⁢x+2)+C
  6. 6.

    Example 2: Evaluate ∫x⁢x2+1⁢𝑑x.

    Solution: We see that we have a function inside of a function. Let u be the inner function.

    ∫x⁢(x2+1⏟u)1/2⁢𝑑x

    Once we find u, differentiate to find d⁢u, and then solve for d⁢x. Thus, we have

    u = x2+1
    d⁢u = 2⁢x⁢d⁢x
    12⁢x⁢d⁢u = d⁢x

    Plugging this in,

    ∫x⁢(x2+1)1/2⁢𝑑x = ∫(x2+1)1/2⁢x⁢𝑑x
    = ∫(u)1/2⁢x⁢d⁢u2⁢x
    = ∫u1/2⁢12⁢𝑑u
    = 12⁢∫u1/2⁢𝑑u
    = 12⋅23⁢u3/2+C
    = 13⁢u3/2+C

    Replacing u, we find

    ∫x⁢x2+1⁢𝑑x=13⁢(x2+1)3/2+C
  7. 7.

    Example 3: Evaluate ∫exx⁢𝑑x.

    Solution: For the purposes of facilitating the Calculus, we rewrite the square root so that x=x1/2.

    u = x1/2
    d⁢u = 12⁢x−1/2⁢d⁢x
    2⁢x1/2⁢d⁢u = d⁢x

    Thus, we have

    ∫exx⁢𝑑x = ∫eu⋅x−1/2⋅2⁢x1/2⁢𝑑u
    = ∫eu⋅2⁢𝑑u
    = 2⁢∫eu⁢𝑑u
    = 2⁢eu+C

    Hence,

    ∫exx⁢𝑑x=2⁢ex1/2+C
  8. 8.

    Example 4: Evaluate ∫x⁢4+x⁢𝑑x

    Solution: Let u=4+x, which means d⁢u=d⁢x. Plugging in what we have, we see that

    ∫x⁢4+x⁢𝑑x=∫x⁢u⁢𝑑u

    Thus, we still have to deal with the x that has remained in the problem. We can handle this, by solving for x in terms of u.

    u = 4+x
    x = u−4

    Thus, the integral now becomes,

    ∫x⁢u⁢𝑑u = ∫(u−4)⁢u⁢𝑑u
    = ∫(u3/2−4⁢u1/2)⁢𝑑u
    = 25⁢u5/2−83⁢u3/2+C

    Thus,

    ∫x⁢4+x⁢𝑑x=25⁢(4+x)5/2−83⁢(4+x)3/2+C
  9. 9.

    Substitution and Definite Integrals If we consider the integral

    ∫abf′⁢(g⁢(x))⁢g′⁢(x)⁢𝑑x

    We have two methods we can use for evaluating the definite integral.

    • •

      Integrate as a indenfinite integral and then evaluate the indices afterwards (in this class, you may not use this method).

    • •

      Make a substitution and change the indices (you are required to use this one). In performing this method, we let u=g⁢(x) and d⁢u=g′⁢(x)⁢d⁢x. We then change the indices by letting u1=g⁢(a), and u2=g⁢(b). To make the integral

      ∫abf′⁢(g⁢(x))⁢g′⁢(x)⁢𝑑x=∫g⁢(a)g⁢(b)f′⁢(u)⁢𝑑u
  10. 10.

    Example 5: Evaluate ∫121x2⁢1−1x⁢𝑑x.

    Solution: Let

    u = 1−1x
    d⁢u = 1x2⁢d⁢x
    u1 = 1−11=0
    u2 = 1−12=12

    Plugging these values in, we get the following,

    ∫121x2⁢1−1x⁢𝑑x = ∫01/2u⁢𝑑u
    = 23⁢u3/2|01/2
    = 23⁢(1−(12)3/2)
  11. 11.

    Example 6: Evaluate ∫0π/2cos⁡x(1+sin⁡x)2⁢𝑑x.
    Solution: Let u=1+sin⁡x, and d⁢u=cos⁡x. Thus u1=1+sin⁡(0)=1, and u2=1+sin⁡(π/2)=2. Thus, we get,

    ∫0π/2cos⁡x(1+sin⁡x)2⁢𝑑x = ∫12d⁢uu2
    = −1u|12
    = −11−(−12)
    = −12
  12. 12.

    Example 7: Evaluate ∫tan⁡x⁢d⁢x
    Solution: We convert to sines and cosines,

    ∫tan⁡x⁢d⁢x=∫sin⁡xcos⁡x⁢𝑑x

    Let u=cos⁡x, d⁢u=−sin⁡x⁢d⁢x, which means d⁢x=1−sin⁡x⁢d⁢u. Thus, we have,

    ∫tan⁡x⁢d⁢x = ∫sin⁡xcos⁡x⁢𝑑x
    = ∫sin⁡xu⋅1−sin⁡x⁢𝑑u
    = −∫d⁢uu
    = =ln⁡|u|+C
    = ln⁡|1u|+C
    = ln|1cos⁡x|+C
    = ln⁡|sec⁡x|+C
  13. 13.

    Example 8: Evalue ∫sec⁡x⁢d⁢x
    Solution: For this problem, we perform a trick,

    sec⁡x = sec⁡x⋅sec⁡x+tan⁡xsec⁡x+tan⁡x
    = sec2⁡x+sec⁡x⁢tan⁡xsec⁡x+tan⁡x

    We play this trick so that we can actually integrate using u-substitution. Thus, we have,

    ∫sec⁡x⁢d⁢x=∫sec2⁡x+sec⁡x⁢tan⁡xsec⁡x+tan⁡x⁢𝑑x

    Let u=sec⁡x+tan⁡x, which means d⁢u=sec2⁡x+sec⁡x⁢tan⁡x⁢d⁢x. Hence, we have,

    ∫sec⁡x⁢d⁢x = ∫sec2⁡x+sec⁡x⁢tan⁡xsec⁡x+tan⁡x⁢𝑑x
    = ∫d⁢uu
    = ln⁡|u|+C
    = ln⁡|sec⁡x+tan⁡x|+C
  14. 14.

    Example 9: Evaluate ∫sec⁡4⁢x⁢d⁢x
    Solution: We can apply the integral formula we just learned above. Let u=4⁢x, so that d⁢u=4⁢d⁢x, which means that 14⁢d⁢u=d⁢x. Thus, we have

    ∫sec⁡4⁢x⁢d⁢x = ∫14⁢sec⁡u⁢d⁢u
    = 14⁢ln⁡|sec⁡u+tan⁡u|+C
    = 14⁢ln⁡|sec⁡4⁢x+tan⁡4⁢x|+C
